# אחת שאלתי - [תורת אסתר]


> לעילוי נשמת הנערה הצדקנית **אסתר גיטה דינר בת רבי מיכאל שלום הלוי שיבדלט"א** — תנצב"ה.

## מה זו התוכנה, ולמה היא נועדה

זו תוכנה שהופכת מחשב רגיל ל"מחשב לימוד" — מחשב שבו אפשר להשתמש **רק** באפליקציית
הלימוד [אוצריא](https://github.com/Otzaria/otzaria) (ספרייה תורנית חינמית בקוד
פתוח), ולא בשום דבר אחר: לא גלישה באינטרנט, לא משחקים, לא תוכנות אחרות — אלא אם
המנהל (ההורה/בעל בית המדרש) אישר אותן במפורש מראש.

התוכנה מיועדת למי שרוצה ללמוד ללא הסחי דעת  
או לתת  לילד/תלמיד מחשב לשימוש בלימוד בלבד, בלי לדאוג
שישתמש בו למטרות אחרות, ובלי צורך לפקח עליו כל הזמן.

## מה כלול בהתקנה

ההתקנה מוסיפה לאוצריא שלושה חלקים שעובדים יחד:

1. **רכיב הרקע** — תוכנה קטנה שרצה ברקע ב-Windows ומפעילה את מצב הנעילה. היא לא
   ניגשת לאינטרנט ולא שולחת שום מידע החוצה — כל התקשורת שלה היא רק בתוך המחשב
   עצמו.
2. **תוסף "סייר קבצים"** — מאפשר לפתוח, להעתיק ולראות קבצים (PDF, Word, תמונות
   וכו') מתוך אוצריא עצמה, בלי לצאת ל"סייר הקבצים" הרגיל של Windows. כשהנעילה
   פעילה, אפשר לראות רק את התיקיות שהמנהל אישר.
3. **תוסף "הגדרות מערכת"** — מאפשר לשלוט בהגדרות המחשב (עוצמת קול, מסך, Wi-Fi
   וכו') מבלי לצאת מאוצריא, ולהפעיל/לכבות את מצב הנעילה.

## רמות החסימה, וכמה היא חזקה בפועל

יש שתי רמות חסימה, מהקלה לחזקה:

- **נעילה רגילה** (ברירת מחדל) — התוכנה עצמה דואגת שאוצריא תהיה התוכנה היחידה
  בחזית, חוסמת מקשים כמו Alt+Tab ומנהל המשימות, ומגבילה את סייר הקבצים לתיקיות
  מאושרות. זו הגנה טובה נגד שימוש אקראי/לא-מתוחכם, אבל **משתמש טכני ונחוש**
  (שמכיר את Windows לעומק) יכול למצוא דרכים לעקוף אותה.
- **נעילה מוקשחת** (אופציונלי, מומלץ) — מתקינים בנוסף רכיב שירות שרץ ברמת
  המערכת (SYSTEM), לא רק ברמת המשתמש. הוא שומר על ההגדרות מפני עריכה, מונע
  סגירה של רכיב הרקע, ומגן גם אם עוברים לחשבון Windows אחר. זו שכבת ההגנה
  המשמעותית ביותר שהתוכנה מציעה.

**חשוב לדעת בכנות:** אין הגנת תוכנה שהיא "בלתי שבירה" לחלוטין. מי שיש לו גישה
פיזית למחשב, הרשאות מנהל ב-Windows, וידע טכני מתקדם, יכול תיאורטית לעקוף כל
הגנה שמבוססת רק על תוכנה. לכן מומלץ גם:
- להגדיר למשתמש חשבון Windows **רגיל** (לא מנהל) — זה חוסם הרבה דרכי עקיפה.
- להקשיח גם את ה-BIOS/UEFI של המחשב (סיסמת BIOS, חסימת אתחול מ-USB, נעילת
  תפריט האתחול) — בהגדרות ← הקשחת BIOS/UEFI יש ניסיון אוטומטי מתוך התוכנה עצמה
  (לא כל פעולה מובטחת להצליח, תלוי ביצרן ובדגם), וכפתור "הדרכה ידנית" עם הסברים
  לכל היצרנים למי שצריך להגדיר זאת בעצמו.
- לדרוש סיסמה + אימות דו-שלבי (Windows Hello) לכל פעולה רגישה (ביטול נעילה,
  שינוי הגדרות) — כך גם מי שמנחש/גונב את הסיסמה לא יוכל לעשות בה שימוש לבד.
| רכיב | מה הוא עושה | תיקייה |
|---|---|---|
| **אחת שאלתי** (`OtzariaBridge.exe`) | תוכנה קטנה שרצה ברקע ב-Windows ומאזינה רק למחשב המקומי. נותנת לתוספים גישה לקבצים ולהגדרות המחשב, ומצב נעילה לאוצריא בלבד. | `bridge/` |
| **סייר קבצים** | עיון, העתקה, העברה, מחיקה, שינוי שם, חיפוש, וצפייה ב-PDF, Word, טקסט ותמונות — מתוך אוצריא. בלי הגשר: תיקיות שאישרתם בלבד. | `file-explorer/` |
| **הגדרות מערכת** | שמע, מסך, בלוטות׳, Wi-Fi, הפעלה וכיבוי, ומצב נעילה עם יציאה בסיסמה (ומגרסה 3.0 נעילה מוקשחת אופציונלית). | `system-settings/` |

## הורדה

[ההתקנה האחרונה](https://github.com/YairDaniel11/otzaria-system-tools/releases/latest):
מורידים את קובץ ההתקנה ומפעילים אותו, ואז מתקינים מתוך אוצריא את שני התוספים
(ההתקנה עצמה מנחה אתכם בזה בסוף התהליך).

נבדקה בפועל על כמה מחשבי Windows.

## אבטחה (למי שרוצה את הפרטים הטכניים)
- **צימוד:** רק תוסף שאושר בחלון של הגשר יכול להשתמש בו. בפעם הראשונה כל תוסף מבקש אישור.
- **נעילה מוקשחת (אופציונלית):** רכיב שירות שמגן על הנעילה מפני סגירת הגשר, עריכת קבצים וחשבון Windows אחר. פרטים ב-[docs/HARDLOCK.md](docs/HARDLOCK.md).
- **אימות דו-שלבי (Windows Hello):** נאכף גם ברמת רכיב ההקשחה (לא רק בגשר) על כל הפעולות הרגישות — ביטול נעילה, שינוי סיסמה, שינוי הגדרות, דילוג על תזמון, הסרה. ר' [docs/SECURITY_NOTES.md](docs/SECURITY_NOTES.md) למגבלות ידועות נוספות.
- **דיאלוגי "פתיחת קובץ" של Windows:** נאכפת עליהם אותה מדיניות תיקיות/סיומות כמו בסייר הקבצים הפנימי, גם בתוכנות חיצוניות מאושרות (DialogGuard).
