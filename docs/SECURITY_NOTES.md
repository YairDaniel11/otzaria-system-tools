# הערות אבטחה

## מה המוצר חוסם (תיאור כללי)

- **נעילת קיוסק:** אוצריא היא התוכנה היחידה בחזית; חסימת קיצורי מקלדת ומנהל המשימות; סייר הקבצים מוגבל לתיקיות שהמנהל אישר.
- **נעילה מוקשחת (שירות SYSTEM):** הסיסמה והגדרות הנעילה נשמרות מחוץ להישג המשתמש הרגיל; כשל = נשארים נעולים (fail-closed); הגשר מזוהה לפי נתיב וחתימה.
- **דיאלוגי פתיחה/שמירה של תוכנות חיצוניות:** נאכפים לפי מדיניות תיקיות וסיומות (DialogGuard).
- **אתחול:** הקשחת אתחול ובדיקת מצב BitLocker/TPM/Secure Boot; הקשחת BIOS אוטומטית היכן שהיצרן תומך (Lenovo, HP עסקי).
- **אימות דו-שלבי:** סיסמה + Windows Hello לפעולות רגישות.
- **שרשרת אספקה ועדכונים:** עדכון חתום (ECDSA), Release רק מ-`main` דרך סביבה עם אישור, בדיקות חוסמות לפני אריזה.
- **מסלולי חירום:** קוד שחזור וקודי גיבוי; נהלי שחזור נמצאים אצל המפתח.
