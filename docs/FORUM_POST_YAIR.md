# **אחת שאלתי - מחשב לימוד לאוצריא, בלי הסחות ומפריעים**

ברוך ה', לאחר ש [@חד-בדרא](/forum/user/%D7%97%D7%93-%D7%91%D7%93%D7%A8%D7%90) יצר בסיס רחב ומדוייק, ולאחר עבודה מאומצת של שנינו, אנו שמחים להגיש לציבור יראי ה' את התוכנה "אחת שאלתי" = תוכנה לחסימת המחשב ללימוד בלבד, עם כמה רמות חסימה, מלא אפשרויות ופונקציות, ועוד ועוד.

**אחת שאלתי** היא תוכנה ל-Windows שהופכת מחשב רגיל ל**עמדת לימוד** שבה אפשר להשתמש **רק** באוצריא ולא בשום דבר אחר - בלי גלישה, בלי משחקים ובלי תוכנות אחרות. התוכנות היחידות שהמנהל אישר מראש הם אלו שיכולות להיפתח.

מתאימה ל:

- **בית מדרש** — עמדות לימוד פנויות לכל מי שנכנס.

- **בית כנסת** — מחשב שנועד לספרייה התורנית ולא לשום דבר אחר.

- **בית** — מחשב לילד או לתלמיד, בלי צורך לפקח עליו כל הזמן (או לעצמך... אל תביאנו לא לידי נסיון ולא לידי בזיון...)

- **ההתקנה מוסיפה לאוצריא שלושה חלקים שעובדים יחד:**

- **הגשר** (OtzariaBridge.exe) — תוכנה קטנה שרצה ברקע, מאזינה **רק למחשב המקומי** ולא שולחת מידע החוצה. היא מפעילה את מצב הנעילה ונותנת לתוספים גישה לקבצים ולהגדרות.

- **תוסף "סייר קבצים"** — מנהל קבצים בתוך אוצריא.

- **תוסף "הגדרות מערכת"** — הגדרות Windows בתוך אוצריא, כולל שליטה במצב הנעילה.

## **מצב נעילה**

- המחשב נעול לאוצריא במסך מלא, עם שורת תוכנות שאושרו ע"י המנהל - בסרגל בצד + שעון מרחף בצד המסך.

- **רק** תוכנות שהמנהל אישר פתוחות לשימוש (למשל וורד, אוצריא, כתבי הקודש וכדו').

- **תזמון נעילה** לפי שעות, עם כמה חלונות זמן ביום.

- **פתיחה זמנית** של המחשב בסיסמה נפרדת.

- **נעילה רגילה** חוסמת מקשים כמו Alt+Tab ומנהל המשימות, ומגבילה את סייר הקבצים לתיקיות מאושרות.

- **נעילה מוקשחת** (אופציונלית, מומלצת): רכיב שירות שרץ ברמת המערכת, שומר על ההגדרות מעריכה, מונע סגירה של הגשר ומגן גם בחשבון Windows אחר.

- **אימות דו-שלבי עם Windows Hello** לפעולות רגישות: ביטול נעילה, שינוי סיסמה, שינוי הגדרות ועוד.

- **הקשחת BIOS/UEFI**: ניסיון אוטומטי מתוך התוכנה, וכפתור הדרכה ידנית לכל היצרנים.

- דיאלוגי "פתיחת קובץ" של Windows נאכפים באותה מדיניות תיקיות וסיומות.

**איך מפעילים?**

- בוחרים **סיסמה** ושומרים **קוד שחזור** בהפעלה הראשונה.

- שכחתם סיסמה? **קוד שחזור**, או **קיצור חירום: Ctrl + Alt + Shift + F12** (במחשבים רבים גם עם Fn).

## **שומר מסך**

כשהמחשב לא בשימוש, אפשר להגדיר שיהיה שומר מסך - עם  מלא אפשריות:

- פסוק

- שעה ותאריך עברי

- זמני היום

- הקדשה אישית (לבחירה)

- כיתוב אישי (כמו שם בית הכנסת לדוגמא)

- אפשר להשתמש בשומר המסך גם כתמונת מסך הנעילה של Windows.

## **תוספים:**

### **תוסף "הגדרות מערכת"**

(הגדרות Windows מתוך אוצריא)

- מסך, שמע, חשמל וסוללה, שעה ותאריך;

- מקלדת, עכבר, מדפסות, התקני USB, בלוטות׳;

- Wi-Fi ומצב טיסה;

- **חיפוש הגדרה**, ותפריטים נפתחים (למשל זמני כיבוי מסך ושינה, ותוכנית צריכה);

- לשוניות נוספות ללימוד ולנעילה: **תוכנות לימוד**, **מצב נעילה**, **נעילת סייר הקבצים**, **שומר מסך**, **אודות**.

### **תוסף "סייר קבצים"**

- סייר הקבצים בסגנון סייר הקבצים של ווידנוס - נותן את המראה המוכר - בתוך אוצריא

- מצבי תצוגה שונים, חיפוש בקבצים ובתוכן הקבצים

- צפייה ב-**PDF, Word, טקסט ותמונות**;

- העתקה, העברה, מחיקה, שינוי שם, וסל מיחזור;

- כשהנעילה (האפשרית, לא חובה) פעילה =  רק התיקיות שהמנהל אישר.

### **הגשר בשורת המשימות**

- אודות ועדכונים, יומן שינויים

- דיווחים:אילו לוגים נשלחו מהתוכנה, עריכה והוספת תיאור ללוגים - לשליחה;

- **צימוד תוספים** — כל תוסף מבקש אישור בפעם הראשונה, ורק מה שאושר מתחבר;

- התקנה/עדכון התוספים באוצריא ופתיחת תיקיית התוספים;

- **צילום מסך** (Ctrl+Shift+F11) ו**צילום אזור** (Ctrl+Shift+F12);

- אייקון שקוף במחשב  ( - בדומה לסמל של וויפרי) סמל קטן ברקע בפינה (גודל ומיקום לבחירה);

- ממשק בעברית ובאנגלית.

#### **כמה דברים שחשוב לדעת:**

אין הגנת תוכנה "בלתי שבירה". מי שיש לו גישה פיזית למחשב, הרשאות מנהל ב-Windows וידע מתקדם יכול תיאורטית לעקוף כל הגנה שמבוססת על תוכנה בלבד.

לכן מומלץ:

- להגדיר למשתמש חשבון Windows **רגיל** (לא מנהל);

- להפעיל **נעילה מוקשחת**;

- להקשיח גם את ה-**BIOS/UEFI** (סיסמה, חסימת אתחול מ-USB);

- לדרוש **Windows Hello** לפעולות רגישות.

הנעילה הרגילה מגינה היטב מפני שימוש אקראי, אבל משתמש טכני ונחוש יכול למצוא דרכים לעקוף אותה. התוכנה נבדקה בפועל על כמה מחשבי Windows.
