# טקסט לפורום אוצריא — תגובה בנושא "עזרה | מחשב תורני" (המשך לפוסט 42773)

---

**עדכון: מה שחסר — מוכן. כלי מערכת לאוצריא 1.0.0**

בהמשך לפוסט הפתיחה כאן (https://otzaria.org/forum/post/42773): שלושת הדברים שהיו חסרים הושלמו.

✅ **תוכנת חסימת אוצריא** — נכתב (C# / .NET 8, קובץ exe יחיד). רץ ברקע, מאזין רק למחשב המקומי (127.0.0.1), ועולה אוטומטית עם Windows.
✅ **סייר קבצים** — עיון, העתקה, גזירה, הדבקה, מחיקה לסל המיחזור, שינוי שם, חיפוש (גם בתוכן), חלונית תצוגה מקדימה, תצוגת פרטים/רשימה/סמלים, וצפייה ב-PDF, Word, טקסט ותמונות. בלי הגשר הוא עובד על תיקיות שאישרתם.
✅ **הגדרות מערכת** — שמע, בהירות, בלוטות׳, Wi-Fi, הפעלה וכיבוי, ו**מצב נעילה** שבו פתוחה רק אוצריא, עם יציאה בסיסמה וקוד שחזור. "נעילה קפדנית" כבויה כברירת מחדל.

שני התוספים בעברית ובאנגלית, עם כפתור "שליחת הערה" דרך מערכת הדיווח של אוצריא.

**הורדה:** https://github.com/e0548433917-gif/achat-shaalti/releases/latest
1. מפעילים פעם אחת את `OtzariaBridge.exe`.
2. באוצריא: התקנת תוסף מקובץ → `file-explorer.otzplugin` ו-`system-settings.otzplugin`.

הקוד עבר לריפו נפרד: https://github.com/e0548433917-gif/achat-shaalti

**עדיין צריך עזרה — כפי שנכתב כאן בשרשור:**
- בדיקה על כמה שיותר מחשבים (Windows 10/11, נייח ונייד) — בעיקר Wi-Fi, החלפת התקן שמע ובלוטות׳.
- **בדיקת אבטחה למצב הנעילה** — ניסיונות "לברוח" ממנו. מי שמוצא פרצה — כפתור "שליחת הערה" או Issue בגיטהאב.
- ⚠️ לפני הפעלת "נעילה קפדנית" — לרשום את קוד השחזור.
