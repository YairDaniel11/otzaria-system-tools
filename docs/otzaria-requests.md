# טיוטות פנייה לצוות אוצריא

## 1. אירוע "בקשת סגירה" (#57)

לפרסם ב-https://github.com/Otzaria/otzaria/issues

**כותרת:** בקשת API: אירוע `app.close_requested` לתוספים (ביטול סגירה במצב נעילה)

שלום רב,
בתוסף "הגדרות מערכת" (מצב נעילה "אחת שאלתי") אנו צריכים לדעת מתי המשתמש מנסה לסגור את אוצריא, ולאפשר לתוסף לבטל את הסגירה כל עוד הנעילה פעילה. היום אין לכך API רשמי, ואנו נאלצים ליירט ברמת חלון Windows (SC_CLOSE), מה שאינו נייד ושביר.

נשמח ל:
- אירוע `app.close_requested` שנשלח לתוסף לפני סגירה, עם אפשרות להחזיר `preventDefault`/`false` כדי לבטל (בדומה ל-`beforeunload`).
- לחלופין, הרשאת מניפסט ייעודית (למשל `app.intercept_close`) שתופעל רק בהסכמת המשתמש.

מצב מנותק כבר נקרא אצלנו דרך `settings.changed` + `app.getConnectivity`, כך שרק אירוע הסגירה חסר.

תודה רבה.

## 3. שיתוף נתונים עם "שמירת סדרים"

ב-SDK הנוכחי `publishedData.listOwn` מחזיר רק רשומות של התוסף עצמו, ואין קריאה חוצת-תוספים. לכן ייבוא הסדרים נעשה כרגע מקובץ ייצוא. אם ייחשף API לקריאת נתונים שתוסף אחר פרסם (או ש"שמירת סדרים" יפרסם סדרים כ-`publishedData`), נוכל לשאוב אוטומטית. פנייה ליוצר "שמירת סדרים" — לבדוק אם קיים ייצוא, ובאיזה פורמט.

## בדיקה 15.10.2026 (ענף dev של Otzaria)
- אין אירוע `app.close_requested` (קיימים רק app.startup / app.command / app.background_keep_alive וכו׳) — היירוט הקיים של SC_CLOSE נשאר.
- `publishedData` כולל רק upsert/remove/listOwn (מסונן לפי pluginId). אין קריאה חוצת-תוספים — הייבוא מקובץ נשאר.
