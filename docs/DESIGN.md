# שכבת העיצוב והממשק של התוספים (סבב 1.11.2026)

עיצוב וממשק בלבד. כל ההוספות הן קבצים חדשים, ובקוד קיים נוספו רק שורות טעינה ורישום. PR #393, ענף `design/ui-upgrade` → `next`.

## קבצים
- `*/css/modern.css` — זהה פיזית בשני התוספים (כמו base.css; בכל שינוי לעדכן את שני העותקים). נטען אחרון ורק דורס מראה. כל הצבעים נגזרים מטוקני אוצריא (`--color-*`) דרך `color-mix`, כך שמצב בהיר וכהה נשמרים. כל ההנפשות כבויות ב-`prefers-reduced-motion`.
- `system-settings/js/sections/kiosk-tabs.js` — מחלק את טאב "מצב נעילה" ללשוניות: סקירה / הגדרות / אבטחה ושחזור / הסברים. לא משנה את kiosk.js: MutationObserver מסמן ומסתיר כרטיסים קיימים אחרי כל רינדור (מחלקה `k-off`). כרטיס הסטטוס, "קוד השחזור לא נשמר" והאשף תמיד גלויים. כרטיס חדש ב-kiosk.js נופל ללשונית "הגדרות" כברירת מחדל; לשיוך אחר יש לעדכן את `classify()`.
- `system-settings/js/sections/cursor.js` + `bridge/CursorApi.cs` — כרטיס "מצביע וסמן טקסט" בתוך מקטע העכבר: גודל, צבע (לבן/שחור/הפוך/צבעוני), איתור ב-Ctrl, שובל, הסתרה בהקלדה, עובי סמן טקסט. עוטף את מקטע `mouse` בלי לשנות את mouse.js. נתיבים `/sys/mouse/cursor/*` (ראו BRIDGE_API.md), ולכן כפופים להרשאת מקטע העכבר בנעילה. בגשר ישן מוצגת הודעה במקום הכרטיס.
- `system-settings/js/palette.js` — פלטת פקודות (Ctrl+K) וכפתור "חיפוש מהיר" בסרגל העליון; מכבדת את `SS.sectionVisible`.

## לא נבדק
- לא נבדק באוצריא אמיתית ולא על Windows. אין dotnet בסביבת הענן — בניית הגשר נבדקת ב-CI של ה-PR.

- מסך פתיחה בהגדרות עם אריחי קיצור (עוצמה, בהירות, Wi‑Fi, נעילה).
- סייר הקבצים: תצוגת אריחים עם תמונות ממוזערות ופס סטטוס עם גודל הבחירה.
